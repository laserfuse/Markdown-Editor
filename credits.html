Technologies

HTML, CSS et JavaScript pour l’application web, avec Vite pour le développement et la compilation.

Le rendu Markdown utilise markdown-it et ses extensions. La coloration syntaxique est assurée par highlight.js, les diagrammes par Mermaid et les formules mathématiques par KaTeX.
